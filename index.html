20 层深度检测架构

从系统属性到进程信任链，全方位覆盖 Android 安全检测的每一个角落

L1 System Properties

检测系统属性中的 Root 相关标记，包括 ro.debuggable、ro.secure、ro.build.tags 等关键字段

getprop / Build.class / System.getProperty
L2 ART Injection (Frida/Xposed/LSPosed)

检测运行时注入框架，包括 Frida 的 ptrace 注入、Xposed/LSPosed 的 Java 方法 Hook

/proc/self/maps / D-Bus / port scanning
L3 Memory Fingerprint (Magisk/Zygisk)

扫描进程内存空间，查找 Magisk 和 Zygisk 的特征字符串、数据结构和指纹模式

/proc/self/mem / ptrace / libmemscan
L4 Mount Check

检查 /proc/self/mounts 和 /proc/mounts 中的异常挂载点，检测 overlay 和 bind mount

/proc/mounts / statfs / fs stat
L5 Side-Channel Analysis

通过侧信道分析检测隐藏的 Root，包括时钟偏移、系统调用时序、缓存特征等

clock_gettime / syscall timing / cache analysis
L6 Root Daemon Detection

扫描 Root 相关守护进程，包括 su daemon、magiskd、ksud 等

/proc/[pid] / ps / netstat / socket scan
L7 Boot Chain Verification

验证启动链完整性，检测 dm-verity、verified boot 状态和 boot 分区篡改

dm-verity / AVB / boot.img analysis
L8 Magisk (mainstream + forks)

全面检测 Magisk 主流版本及其分支变体，覆盖超过 15+ 已知 Magisk 衍生版本

APK signature / native libs / file paths
L9 KernelSU

检测 KernelSU 内核级 Root 方案，包括模块管理器和内核模块特征

/sys/fs/selinux / kernel module / ksud
L10 APatch

检测 APatch 内核补丁方案，包括其内核模块和 AndroidPatch 特征

kernel patch / APatch module / KP module
L11 Hook Framework Detection

检测各类 Hook 框架：Frida、Xposed、EdXposed、LSPosed、ShadowHook 等

PLT/GOT hook / inline hook / JNI hook detection
L12 Custom ROM Identification (50+ ROMs)

识别 50+ 自定义 ROM，包括 LineageOS、Pixel Experience、crDroid 等

build.prop fingerprint / ROM signatures
L13 Firmware Integrity

验证固件完整性，包括系统分区哈希校验和关键文件篡改检测

SHA-256 hash / partition checksum / file integrity
L14 Virtual Framework Detection

检测虚拟化框架和模拟器环境，包括 VirtualXposed、VMOS、Parallel Space 等

emulator fingerprint / VM detection / sandbox ID
L15 Dangerous Apps Detection

扫描设备上已安装的危险应用，包括 Root 管理器、Hook 工具、模拟器等

PackageManager / APK signature / app fingerprint
L16 Magisk Extensions

检测 Magisk 扩展模块，包括 Shamiko、Zygisk-Assistant、MagiskHide Props Config 等

module.json / Magisk module paths / overlay detection
L17 Advanced Threat Detection

高级威胁检测，覆盖反调试、反虚拟化、反沙箱逃逸等对抗手段的检测

anti-debug / anti-VM / evasion technique scan
L18 Network Security Analysis

网络安全分析，检测代理设置、VPN 隧道、DNS 劫持和异常网络连接

proxy detection / VPN scan / DNS audit / iptables
L19 SELinux Policy Audit

SELinux 策略审计，检测策略修改、permissive 模式和自定义 SELinux 规则

sestatus / sepolicy / SELinux mode / policy load
L20 Process Trust Chain

进程信任链验证，从 Zygote 到应用进程的完整信任路径验证

process tree / Zygote verification / trust chain

3 模式隐藏系统

从零副作用的纯检测到激进的游戏级隐藏，灵活适配不同场景需求

Detection Mode

仅检测不隐藏

零副作用 · 默认模式

Hide Mode

智能隐藏 Root

eBPF 防火墙 · Namespace 隔离

Game Mode

激进隐藏 + 性能优化

进程伪装 · HWID 伪装

eBPF Firewall

基于 eBPF 的系统调用级拦截防火墙，在内核层面过滤检测请求，零延迟响应，Android 12+ 支持 BPF CO-RE 技术

Mount Namespace

利用 Linux Mount Namespace 隔离技术，为每个应用创建独立的挂载命名空间，彻底隐藏 Root 相关文件系统条目

LD_PRELOAD Hook

通过 LD_PRELOAD 机制预加载自定义库，拦截和篡改 libc 函数调用，对文件访问、进程枚举等系统调用进行透明重定向

核心技术亮点

融合前沿密码学、微服务架构与内核技术，构建企业级安全评估引擎

Post-Quantum Signature

采用 NIST 标准化的后量子密码签名算法，抵抗未来量子计算攻击，确保检测报告的不可篡改性

ML-DSA-65 CRYSTALS-Dilithium-3 NIST PQC

Microservice Architecture

20 个独立 .so 插件组成的微服务架构，支持热加载和 YAML 驱动配置，灵活扩展检测能力

.so Plugin Hot-Load YAML-Driven

eBPF Firewall

基于 eBPF 技术的系统调用拦截防火墙，在内核层面实现零延迟的检测请求过滤和响应伪造

Syscall Intercept Android 12+ BPF CO-RE

Sandbox Isolation

三级沙箱隔离机制：诱饵隔离、轻量隔离和完全隔离，通过三副本共识确保检测结果可靠性

3-Replica Consensus Bait/Light/Full Namespace Isolation
